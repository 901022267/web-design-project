# Explore Lesotho Tourism Website

A five-page responsive tourism website made for a student web-development assignment.

## Pages
1. `index.html` — Home page and featured highlights
2. `about.html` — About Lesotho, quick facts and responsible tourism
3. `services.html` — Destinations, activities, accommodation ideas and a Maletsunyane Falls feature
4. `gallery.html` — Interactive image gallery with Bootstrap modal and previous/next controls
5. `contact.html` — Booking enquiry form with HTML5 and JavaScript validation

## How to run
- Extract the ZIP file.
- Open `index.html` in a browser.
- An internet connection is needed for Bootstrap, Google Fonts and the remote demonstration photographs.

## Technologies and assignment features
- Semantic HTML5: `header`, `nav`, `main`, `section`, `article`, `footer`
- External CSS with typography, colour palette, spacing, hover effects, transitions, cards, grid and responsive styling
- Bootstrap 5 navbar, grid, cards, badges, alerts, form controls and modal
- JavaScript: current year, form validation and feedback, message character counter, gallery preview, previous/next photo controls and keyboard arrows
- Five interconnected pages with working navigation
- Form fields include name, email, phone, date, destination, visitor count, interests, message and consent checkbox

## Important notes
- This is a front-end student project. The enquiry form does not send or save personal information and does not create a real booking.
- Images are loaded from Unsplash remote URLs for demonstration. Replace them with your own appropriately licensed images if required.
- Before publishing, check all local facts, image permissions, and service availability with reliable sources.
- To host it, upload the extracted folder contents to a static hosting service such as GitHub Pages or Netlify.
